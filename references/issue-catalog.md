# PPT-HTML 问题目录

用于在自动验收中把用户描述快速映射到排查方向；命中后仍须执行
[qa-checklist.md](qa-checklist.md) 所要求的量测与回归。

## 字号与导出

| 现象 | 根因 | 处理 |
|------|------|------|
| PPT 字号发虚/发跳 | HTML 任意 px 导出时四舍五入 | 使用整数 pt token |
| 投影正文偏小 | body 约 16px（9.6pt） | 提升至 20px / 12pt |
| 改字号后全局翻车 | 未重测布局 | 强制全量重测文字、对齐、图片、空白项 |

## 溢出与裁切

| 现象 | 根因 | 处理 |
|------|------|------|
| 列表中文半截 | flex 挤高度加 line-clamp | 取消错误 clamp，保留足够行高 |
| 卡片末条 bullet 消失或下半截被底栏盖住 | 列表父容器 `overflow: hidden`，且正文区未为 `.foot` / 指标条留高 | 对 `ul` 与父容器同时量测；增高卡/行或缩短文案，先固定底栏高度再分配正文区 |
| 截图中正文下沿、右沿或局部笔画被遮住 | 底栏、横线、色块、图片、透明遮罩、固定高度或任意叠层与文字发生可见相交 | 截图优先判失败；放大问题区，回溯 DOM 层级、z-index、几何边界和字体渲染，留出真实视觉间距后重渲染确认 |
| 检查通过但截图中仍少字 | 自动检查只覆盖已知 CSS/DOM 模式，未覆盖字体度量、叠层、透明元素或其他视觉相交 | 以截图为最终依据；不为现象穷举新 CSS 规则，先修复该页布局，再把通用视觉验收要求纳入回归 |
| 图注或标签显示省略号 | 用 `text-overflow: ellipsis` 代替排版调整 | 仅允许明确可截断的辅助标签；其他场景扩容、换行或缩短文案 |
| 措施溢出到结果行 | 等分行高不足两行文案 | 合理字号、增加措施行高度并减字 |
| 层名和说明粘连 | 标签列过窄加 nowrap | 将标签列扩至约 7em+ |
| 总览页到处裁切 | 信息密度高且被 hidden 掩盖 | 减少 bullet，重分配 flex/grid |
| 出画布底边 | 子项固定高度超过父级 | 使用列 flex，并设置 `min-height: 0` |

## 对齐

| 现象 | 根因 | 处理 |
|------|------|------|
| 左右底边不齐 | grow 被禁用或一栏未撑满 | `height: 100%` 加底卡 `flex: 1` |
| 三卡标题不齐 | 图片区随文案变高 | 固定图片比例与文案 grid 行轨 |
| 底图与底注不齐 | 左右 padding 不一致 | 统一底边 inset |

## 图片

| 现象 | 根因 | 处理 |
|------|------|------|
| 内容页图片被裁或变形 | 媒体框未按源图比例预留，误用 `cover` 或 `fill` | 先按源图长宽比重设媒体框；使用 `contain` 或同比尺寸，并重新分配文字区域 |
| 图片四周留白 | 媒体框比例与源图不一致或高度链断开 | 使媒体框与源图保持同一长宽比并补齐高度链；不要用裁剪或拉伸消除留白 |
| 小图溢出底栏 | 图片固定高加图注 | 去除固定高，父级锁高、图片 flex |
| 封面/过渡页/封底背景被替换 | 改写母版背景图引用，或以页面图片、伪元素、行内样式覆盖背景 | 恢复 `assets/brand/` 中对应的固定背景图引用，删除覆盖；运行 manifest 哈希校验后重新截图验收 |
| 引用 docs 路径 | 未本地化 | 移入 `assets/media/` 并更新引用 |

## 空白与资源

| 现象 | 根因 | 处理 |
|------|------|------|
| 栏底空一大块 | 普通解释页内容没有按设计分配，或未记录的空白 | 先核对是否为有意留白；仅非设计留白时再调整内容或让主模块伸展，不得为填满而压缩主视觉或新增卡片 |
| 卡片内字少心空 | `justify-content: center` | 使用 `flex-start` 或调整 flex |
| 换机后图片裂开 | 绝对或外部路径 | 仅引用统一媒体目录 |
| 目录脏 | 弃用图未删除 | 对账引用集合并删除弃用资源 |

## HTML 转 PPTX 的文字还原

混合版流程的文字真值来自 P3 采集；下表症状按“采集 → 标定 → 计划 → 渲染”顺序排查。

| 现象 | 根因 | 处理 |
|------|------|------|
| 行距整体比 HTML 大 ~1.2 倍 | `a:spcPct` 是字体自然行高的倍数（微软雅黑约 1.205em），不是 CSS 行高 | 改写 `a:lnSpc/a:spcPts` 精确磅值：`round(lineHeightPx × 0.6 × 100)` |
| 文字整体偏上或偏下 1–3px | 文本框顶到基线距离未按渲染器标定 | 用 `calibrate-hybrid-text.py` 按字号/行高组合实测 `baselineFromBox`，组装时反推 `boxY` |
| 混排行第二行盖住第一行或从卡片左缘起排 | 同一文本节点内各行 `x` 不同（加粗前缀 + 正文），却按首行 x 画整段 | 逐行检查 `lines[]`，`x` 或行距偏差 >2px 时按行拆成独立文本框 |
| 中西文混排行比 HTML 宽、末尾溢出 | LibreOffice 在每个 CJK↔西文边界加约 0.25em | 按边界数做负字距补偿（`−0.25em × 边界数 ÷ 字间数`），限幅 ±0.2em；纯中文/西文不补 |
| 半透明文字在 PPT 中明显变深 | PPTX 文本框不支持字符级 alpha，`rgba()` 被写成实色 | 标记 `bitmapOnly`，字形保留在背景位图，不生成文本框 |
| 竖排 CONTENTS 变大、变正、溢出画面 | `writing-mode: vertical-rl` 被按横排绘制，还丢了 alpha | 标记 `bitmapOnly: vertical-writing`，保留在位图；不要用横排框硬还原 |
| 白字底部像被裁掉 | 文字整体低 2px，下沿离开色块落在浅色底上 | 不是裁切，先修基线；同时检查色块边界与文字墨迹的相对位置 |
| PowerPoint 打开后位置略移 | 基线按 LibreOffice 标定，渲染器不同 | 交付报告注明未实测项；必要时在目标渲染器重跑标定 |

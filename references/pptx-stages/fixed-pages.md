# 固定版式页面复原

## 进入条件

P3 已通过。

## 必读

1. [HTML 转 PPTX 工作流](../html-to-pptx.md)；
2. `exports/pptx/coordinate-map.json`、`template-review.md`、`tasks.md`、`pptx-stage-gates.md`；
3. 对应 HTML 页、框线图和品牌母版映射。

## 执行

复原封面、目录、过渡页和封底的文字及页面私有固定元素。每个文字框和可见文本边界必须与框线图一致；检查
字体、换行、裁切、重叠和层级。页数、标题、副标题和目录条目只能以 `assets/deck.js` 和实际 HTML 为准。

目录页与目录续页必须套用 P3 已生成的目录模板，不得逐页重做固定元素。`build-agenda-template.mjs` 产出的目录 PPTX/
复核文档只能作为结构生成证据，**不能单独证明 P4 视觉通过**；仍须在 P6 完成渲染并与 HTML 逐页比对。本阶段对目录页只配置右侧目录项：

1. 按实际 HTML 写入编号与主标题；不新增副标题、图标或自创卡片样式。
2. 单页 1–12 项；超过 12 项时按续页均分，页数为 `ceil(N / 12)`。
3. 1–6 项用母版基准尺寸；7–12 项按数量等比压缩高度、编号块、圆角与行距。
4. 列表作为整体相对左侧“目录”中心线垂直居中；只允许调整列表 top 与条目参数，不得改动模板固定元素。
5. 若任意目录页的固定元素与模板不一致，判 P3 失败并回退修复目录模板，而不是在 P4 局部打补丁。
6. 右侧条目必须为“独立高清条背景图 + 独立高清编号方块 + 可编辑编号/标题”；若用原生形状重绘条背景或编号方块导致与 HTML 不一致、将两者合并并按条目整体非等比缩放，
   或编号/标题不可编辑、错位，判本阶段失败并回退修复目录模板链路。

## P4 检查与交接

写入 `exports/pptx/fixed-pages-review.md`，按页记录元素边界、文字校验、框线匹配、异常及复测结论。目录页
另记：所用模板标识、本页目录项数量/内容、压缩参数、列表垂直居中结果，以及固定元素是否与模板一致。所有
固定版式页通过后，在 `pptx-stage-gates.md` 标记 P4 通过。

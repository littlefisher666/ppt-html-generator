# 内容页并行复原与逐页检查

## 进入条件

P3 已通过，`P3/framework-deck.pptx` 已包含全部 30 页的背景、Logo、标识线、主标题、副标题与固定页完整内容。

## 必读

1. [HTML 转 PPTX 工作流](../html-to-pptx.md)；
2. `pptx/P2/coordinate-map.json`、`P3/framework-review.md`、`P1/tasks.md`、`P3/pptx-stage-gates.md`；
3. 当前页面的 HTML、框线图、截图和实际媒体资源。

## 执行

1. 按内容页分配多个 subagent。每个 subagent 只处理分配页面、保存该页检查记录与交接信息；不得并发修改
   共享 PPTX 基础结构、页序、模板元素或坐标清单。共享问题由主代理串行修复，并重测所有受影响页面。
2. 仅在 P3 已生成的内容安全区内工作；不得重绘、移动或覆盖背景、Logo、标识线、主标题与副标题，也不得把 HTML 页面截图、隐藏文字截图或框线图写入最终页面。
3. 依据 P2 元素清单逐个复原业务区文字、基础形状、线条、箭头、表格与普通图片；校验文字框和可见文本边界位于对应框线内，无异常换行、裁切或重叠。
4. 仅将单个复杂图表、系统截图或图内文字不可拆分的组合视觉作为独立高清图片组件。校验媒体比例、层级和框线匹配；复杂或不支持元素的
   降级方式必须记录。
5. 每页生成后立即渲染，并与 P2 HTML 基准截图生成叠加图、差异图；未通过不得继续标记该页通过。每页通过后立即写入检查记录；不得等全部内容页完成后再集中验收。

## P4 检查与交接

每页写入 `pptx/P4/page-checks/<页码>-<文件名>.md`，记录负责 subagent、文字/媒体/其他元素的目标和实际
边界、框线校验、比例、层级、异常、降级、叠加图/差异图路径与复测结论。将 subagent 原始交接记录保存到
`pptx/P4/subagent-handoffs/`。所有内容页均通过后，在 `P4/pptx-stage-gates.md` 标记 P4 通过。

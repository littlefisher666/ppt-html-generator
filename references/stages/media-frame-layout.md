# 媒体框预留

## 进入条件

G4 已通过。必须读取 `exports/image-inventory.md`；它是本阶段唯一的图片规划依据。

## 执行

对每个内容页，先按每张源图的长宽比在正文安全区确定媒体框的位置、宽高与图注区。媒体框必须以
`aspect-ratio` 或等价同比尺寸实现。确认所有媒体框后，再计算剩余正文区；不得先铺满文字后压缩、插入、
遮盖或任意缩小图片。

项目图片必须完整可见并保持原始比例：使用 `object-fit: contain` 或等价同比实现，禁止 `fill` 拉伸和
`cover` 裁剪。安全区无法容纳时，调整版式、拆分/缩短文案或减少同页图片，不得改变比例或裁掉画面。
封面、章节、封底固定母版背景和 Logo 不属于项目图片。

## G5 检查与记录

逐页检查媒体框位置、宽高、`aspect-ratio`、图注区和剩余正文区；媒体框比例必须与清单源图一致。将结果
写入 `exports/media-frame-review.md`。G5 通过前，内容页不得填入实际正文、表格、数据卡或说明文字。

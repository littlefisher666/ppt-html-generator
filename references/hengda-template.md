本文件记录恒达智控母版的 HTML 映射。原始 PPTX 不是生成时依赖；若用户临时放回用于
复核，必须只读使用并原地保留，只有用户明确确认后才可删除。本文件与 `assets/hengda/`
中的品牌专属素材、以及 manifest 所列的 `assets/shared/` 公共素材，是后续生成的权威母版映射和素材来源。

## 目录版式几何与效果

- 目录版式自身的 `<p:bg>` 是从浅蓝到白色的纵向渐变，不能替换成纯白底。起点为主题
  `accent2 #297FD5` 经 `lumMod=20%`、`lumOff=80%` 处理得到 `#D4E5F7`，再使用
  `alpha=79%`；在白色底上合成为约 `#DDEAF9`。终点为 `bg1 #FFFFFF`，OOXML 角度
  `5400000`（90°）映射到 CSS 为 `linear-gradient(180deg, …)`。
- `agenda-welding.jpg`、白色前景渐变层和 `#00468F` 前景渐变层虽然保留在版式 OOXML
  中，但三者的 `<p:cNvPr>` 均明确设置 `hidden="1"`；它们不得在默认 HTML 目录页中
  显示。只有用户明确要求启用母版隐藏备选背景时才能显示这些对象。
- 彩色 Logo：`x=1240`、`y=40.67`、`w=348.17`、`h=53.66`。
- `CONTENTS`：`x=130.92`、`y=52.11`、`w=194.92`、`h=784`，80pt、粗体、
  `accent1` 20% 透明度、东亚竖排。
- “目 录”位于同一个东亚竖排文本框：`x=330.59`、`y=252.19`、`w=157.25`、
  `h=383.83`，66pt、粗体、字符间距 6pt、`accent1`，保留约 12px 左右、6px 上下
  内边距。HTML 可在同一个标题容器内分别包裹两个字以稳定复现浏览器排版，但两个字不得
  脱离共同容器自由定位。
- 中部圆形箭头为 `x=384.33`、`y=419.23`、`49.76×49.76`，其中心点
  `x=409.21`、`y=444.11` 与“目/录”标题容器中心完全相同。内部三角形是向右的等边
  三角形，可见包围盒约 `10.90×12.64px`；HTML 中将该包围盒的水平、垂直中心都固定
  在圆心，不能沿用旋转前尺寸或子图形偏移。“目—圆形箭头—录”必须共用同一垂直
  中心轴，两个字在符号上下保持对称间距。
- 右侧最多 6 行，统一 `x=680.84`、`w=708.66`、`h=75.59`；各行 y 为
  `148.33 / 266.94 / 385.55 / 504.15 / 622.76 / 741.37`。
- 每行数字块与条目同起点，为 `75.59×75.59px` 的 `accent1` 圆角方块，外线宽
  `3.33px`；数字 28pt、白色、常规字重。标题从条目左侧约 `118.11px` 处开始，
  18pt、微软雅黑、常规字重。
- 条目本体是 `accent5` 15% 到透明的水平渐变圆角条，并带同色渐隐边线；不要替换成
  圆形编号、分隔线卡片或带副标题的自创组件。

## 使用边界

- 允许在正文安全区内按内容组合 grid、table、figure 或语义文本块。
- 不允许移动/重绘品牌 Logo、母版横线或对应版式背景来制造另一套视觉系统。
- 背景照片使用 `cover`；Logo 使用真实 PNG 和 `contain`，不得拉伸或重画。
- 不要求每一页使用全部 7 个素材；必须按版式使用正确素材，并确保 deck 至少使用母版 Logo、
  内容页 chrome，以及实际出现的封面/章节/封底对应素材。
